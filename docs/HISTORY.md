# История разработки и ошибки

## Этап 1. SHVDN-мод и клиент с захватом

- Собран `GtaRadioMod` (SHVDN) + клиент `GtaRadio` (WinForms-трей).
- Захват: WASAPI process loopback, вывод через NAudio.
- Первый запуск: игра грузится, мод стартует (`Started script GtaRadioMod.GtaRadioMod`),
  но появляются фризы каждые несколько секунд.
- Фризы не ушли после удаления `SET_VEHICLE_RADIO_ENABLED` и duck-логики.
  Мод временно убран, игра вычищена (`_gtr_backup`).

## Этап 2. RPF и имя станции

- `CodeWalker.Core` на Enhanced не читает RPF (Gen9-ключи):
  `keys generate failed: Value cannot be null. (Parameter 'src')`.
- Найден рабочий `gta-patch` из проекта дубляжа; им извлечён `global.gxt2`,
  найдена метка `RADIO_02_POP` = `0xB5DD6F19`.
- Первая правка положена в `mods/x64b.rpf` — игра её не читает.
- Правка перенесена в `mods/update/update.rpf`, имя появилось.
- Ошибочный откат этой правки (решил, что она даёт шум) — правка восстановлена;
  имя станции на звук не влияет.

## Этап 3. Захват звука: ошибки

1. `InvalidCastException: Unable to cast COM object ... IAudioClient ... E_NOINTERFACE`.
   Причина: устройство из закрытого `MMDeviceEnumerator`. Фикс: выбор по ID,
   новый enumerator, `Dispose`.
2. Повторный `E_NOINTERFACE` из-за STA-потока WinForms. Фикс: открытие loopback
   на MTA-потоке.
3. Зацикленный гул: клиент каждые 2–5 с переключался Spotify <-> Яндекс и
   перезапускал захват. Фикс: гистерезис выбора источника.
4. Гул из-за формата: устройство отдаёт `Extensible`, `SubFormat=...0003`
   (float32), а код считал формат 16-битным. Фикс: определение float по `SubFormat`.
5. Запись захвата подтвердила музыку (`RMS 0.005`, flatness 0.2), но при реальном
   выводе пользователь слышал шум/наложение: исходная сессия продолжала играть,
   штатное радио включалось обратно.
6. Мод выключал радио один раз; игра включала его снова. Фикс: удерживать
   `SET_VEHICLE_RADIO_ENABLED(false)` каждый тик, пока станция активна.
7. Принудительное убийство клиента оставляло сессии замьюченными — плеер молчал,
   захват писал нули. Отсюда правило: не убивать клиент силой, снимать мьюты.

## Этап 4. Разворот на «пульт»

Изучены рабочие моды (см. `MODS-MAP.md`): sahailee/GTA-Spotify-Radio и CiderGTA
не захватывают звук — они управляют плеером и показывают метаданные.
Решение: убрать захват и вывод полностью.

Текущая схема:

- клиент читает SMTC и пишет `%LOCALAPPDATA%\GtaRadio\state.txt`;
- SHVDN-мод на станции `RADIO_02_POP` глушит штатную музыку, показывает HUD,
  на входе в машину посылает медиа-клавишу play, на выходе — pause;
- звук плеера идёт напрямую, мод его не касается.
