# Инструкция для агента на ПК (DeepSeek): сборка, установка, проверка в игре

> **Раунд 2 (после падения игры): [DEEPSEEK-NEXT.md](DEEPSEEK-NEXT.md).** Этот файл — общий чек-лист.

Ты — руки на компьютере пользователя. Код написан заново (Claude, версия 2.0), всё лежит в `src/`.
Твоя задача — собрать, поставить, проверить в игре по чек-листу и вернуть результаты.
Не переписывай архитектуру и не добавляй своё; если что-то не работает — собери логи и опиши, что видишь.

## Жёсткие правила

1. **Никакого своего интерфейса поверх игры** (никаких HUD, плашек, DRAW_RECT, TextElement).
   Трек показывается только штатно: лента уведомлений игры и дисплей радио в машине.
2. **Не трогать аудиоустройства и настройки Windows.** Агент меняет только громкость
   приложения-плеера в микшере на время эфира и сам её возвращает (журнал `sessions.json`).
3. **Только оверлей `mods\`.** Оригинальные RPF не менять. Перевод и радио-озвучку не ломать.
4. Код в `legacy/` — старая версия 1.x, **мёртвый**. Не запускать, не возвращать, не копировать оттуда.
   В ней был баг гула: захват в режиме EXCLUDE (флаг 1 вместо 0) ловил собственный вывод.
5. Без эмодзи в коде, коммиты без `Co-Authored-By`.

## Как устроено (коротко)

```
Плеер (Яндекс Музыка / Spotify / любой с медиасессией Windows)
   │  звук процесса (WASAPI process loopback, INCLUDE дерева процессов плеера)
   ▼
GtaRadio.Agent.exe (трей) ── приглушает плеер в микшере до -60 дБ и компенсирует это в захвате
   │  общая память Local\GtaRadio.v1: PCM float32 stereo + метаданные + команды
   ▼
scripts\GtaRadio.Mod.dll (SHVDN, в процессе игры)
   - занимает RADIO_02_POP: аудиосцена + заморозка + радио машины в OFF (схема MichonGoddijn231849/gta-spotify-radio)
   - играет поток из процесса игры (NAudio WASAPI), громкость следует игре
   - трек: лента уведомлений + Scaleform dashboard SET_RADIO
   - сам запускает агент; агент закрывается после игры
```

Название станции «AUX Radio» в колесе — одна строка GXT2 в `mods\update\update.rpf`
(метка `RADIO_02_POP` = `0xB5DD6F19`), её ставит `installer\patch_station.ps1`.

## Шаг 0. Убрать старую версию

1. Закрой старый трей-клиент `GtaRadio.exe` (1.x) через его меню «Выход». Не убивай процесс силой.
2. Открой «Микшер громкости» Windows: Яндекс Музыка и Spotify не должны быть в mute или на 0.
   Если стоят — верни ползунок руками и сообщи пользователю.
3. `<game>\scripts\GtaRadioMod.dll` (старый мод) — `build.ps1 -Deploy` сам уберёт его в
   `<game>\GtaRadio\backup\legacy\`. Не удаляй его вручную.

## Шаг 1. Сборка и быстрая установка

```powershell
git pull
.\build.ps1 -GtaPatchDir "<путь к папке gta-patch>" `
            -ShvDir "G:\GTA5\Grand.Theft.Auto.V.Enhanced-InsaneRamZes" `
            -Deploy "G:\GTA5\Grand.Theft.Auto.V.Enhanced-InsaneRamZes"
```

- `-GtaPatchDir` — папка с `gta-patch.exe` из проекта дубляжа (`music-studios\game-dub\games\gta5\tools\gta-patch`).
- `-ShvDir` — можно указать саму папку игры: SHV и SHVDN там уже стоят, скрипт только возьмёт
  оттуда `ScriptHookVDotNet3.dll` для компиляции и скопирует файлы в payload установщика.
- Нужен .NET SDK 8. Если ISCC не найден — установщик не соберётся, это нормально на этом шаге.

После `-Deploy` в игре должно быть:

```
scripts\GtaRadio.Mod.dll  scripts\NAudio.Core.dll  scripts\NAudio.Wasapi.dll  scripts\GtaRadio.Mod.ini
GtaRadio\GtaRadio.Agent.exe
GtaRadio\tools\GtaRadio.Gxt2.exe  GtaRadio\tools\gta-patch\...  GtaRadio\tools\patch_station.ps1
```

## Шаг 2. Проверить утилиту GXT2 на настоящем файле (без записи в игру)

```powershell
$g = "G:\GTA5\Grand.Theft.Auto.V.Enhanced-InsaneRamZes"
& "$g\GtaRadio\tools\gta-patch\gta-patch.exe" extract $g "$g\mods\update\update.rpf" "$env:TEMP\gxt" x64/patch/data/lang/russian_rel.rpf/global.gxt2
Get-ChildItem "$env:TEMP\gxt" -Recurse -Filter global.gxt2
& "$g\GtaRadio\tools\GtaRadio.Gxt2.exe" get <путь к извлечённому global.gxt2> RADIO_02_POP
```

Ожидание: печатает `AUX Radio` (станцию уже переименовывали раньше).
Если `[ERROR] not a GXT2 file` / `second magic missing` / `bad string offset` — **стоп**, пришли
пользователю первые 64 байта файла (`Format-Hex -Count 64`) и текст ошибки. Правку не делать.
Если команда extract отличается (другой синтаксис пути) — запиши правильный вариант.

## Шаг 3. Скрипт имени станции (сначала сухой прогон)

1. Сделай ручную копию: `mods\update\update.rpf` -> `D:\backup\update.rpf.before_gtaradio` (вне папки игры).
2. Сухой прогон: `powershell -ExecutionPolicy Bypass -File "$g\GtaRadio\tools\patch_station.ps1" -GameDir $g -DryRun`
   Ожидание в `$g\GtaRadio\patch_station.log`: `original saved: 'Non-Stop-Pop FM'` (или русское название из
   оригинального `update\update.rpf`) и `already 'AUX Radio'` для обоих языков.
3. Проверка отката на копии: `... -Uninstall` должен вернуть исходное имя, затем запуск без ключей — снова `AUX Radio`.
   После каждого шага проверь через extract + `GtaRadio.Gxt2.exe get`.
   В `patch_station.ps1` функция `Put-Entry` помечена `[CHECK]`: если `gta-patch put` кладёт файл не туда
   (имя не меняется или ломается другой язык) — верни копию update.rpf, выясни правильный синтаксис put
   (`gta-patch.exe` без аргументов печатает справку) и поправь только `Put-Entry`.
4. Если что-то сломалось — верни копию из пункта 1. Озвучка должна остаться как была.

## Шаг 4. Проверка в игре (главное)

Перед запуском: включи музыку в Яндекс Музыке (SMTC-сессия Яндекса появляется только после старта воспроизведения).

Логи: `%LOCALAPPDATA%\GtaRadio\mod.log`, `agent.log`, `<game>\ScriptHookVDotNet.log`.

| # | Действие | Ожидание | Что записать |
|---|---|---|---|
| 1 | Запустить игру, загрузиться в сюжет | mod.log: `[OK] loaded, station=RADIO_02_POP audio=True`; через ~3 с появляется значок агента в трее, agent.log: `game link open, rate=48000` | строки логов; если `audio=False` — строку `[ERROR] audio init` |
| 2 | Сесть в машину, выбрать в колесе AUX Radio | штатная Pop не звучит; mod.log: `mute scene: ...`; колесо показывает OFF (так и задумано при VehicleOff) | какая сцена стартовала |
| 3 | Слушать 1-2 минуты | играет музыка из Яндекса, **без гула, эха и двойного звука**; Яндекс в микшере Windows почти на нуле | agent.log: `[OK] capture pid=...` и `calibrate before=... after=... makeup=...` |
| 4 | Сменить трек в Яндексе | уведомление в ленте игры «AUX Radio: Артист - Трек»; от первого лица — трек на дисплее радио | работает ли дисплей |
| 5 | Пауза (Esc) и обратно | музыка замолкает и продолжается | |
| 6 | Выйти из машины | через ~1.2 с Яндекс на паузе, громкость Яндекса в микшере вернулась | |
| 7 | Сесть обратно | Яндекс снова играет в игре | станция осталась AUX Radio? |
| 8 | Переключить станцию на другую | играет штатная станция, Яндекс на паузе | |
| 9 | F7 / F8 / F6 в машине на AUX Radio | пауза / следующий / предыдущий | |
| 10 | Разговор персонажей, звонок | музыка тише | |
| 11 | Закрыть игру | через ~3 с агент сам закрывается (значок пропадает), Яндекс на паузе, громкость в микшере исходная | |
| 11a | В трее «Выключить AUX Radio до перезапуска игры» во время игры | агент закрылся и мод не поднимает его снова; громкость плеера исходная | |
| 12 | Эксперимент: в `scripts\GtaRadio.Mod.ini` поставить `MuteStrategies=Scene,Freeze`, перезапустить игру | слышна ли штатная Pop? что показывает колесо? | ответ — решит, можно ли показывать «AUX Radio» в колесе в эфире |
| 13 | То же со Spotify | как 2-8 | |

Если на шаге 3 гул или эхо: пришли строку `calibrate` и `capture`. Если музыка очень тихая/громкая —
поправь `VolumeDb` в ini (это подстройка под штатные станции) и запиши значение.

## Шаг 5. Установщик

После успешной проверки: установи Inno Setup 6, `.\build.ps1 ... -Iscc "<ISCC.exe>"` без `-Deploy`.
Проверь на игре: установка (имя станции, бэкап в `GtaRadio\backup\`), удаление (имя вернулось,
озвучка на месте, SHV/SHVDN не удалены).
